Privacy Policy

PB Blake Uploader · last updated 30 October 2026

Summary

PB Blake Uploader is a personal tool used by one person — its author — to upload clips to YouTube channels that same person operates. It has no other users, collects nothing from anyone else, and transmits nothing to any third party beyond Google's own APIs.

Information it handles

  • Google account access. When the author signs in, Google issues an access token for their own YouTube channels. This token is stored only on the author's own computer and is never transmitted anywhere except to Google.
  • Video files and their titles, descriptions and tags. These are created by the author and sent to YouTube as uploads.
  • Video titles already on the author's channels. Read back from YouTube so the same clip is not posted twice.

Information it does not handle

  • No data about viewers, subscribers or any other person
  • No analytics, advertising or tracking of any kind
  • No accounts other than the author's own
  • No data is sold, shared or disclosed to anyone

Storage and retention

Access tokens are kept in a local file on the author's computer for as long as the tool is in use, and are deleted when that file is deleted. Nothing is stored on any server, because the tool has no server.

YouTube API Services

This tool uses YouTube API Services. By using it, the author is subject to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. Access granted to this tool can be reviewed and revoked at any time at myaccount.google.com/permissions.

Contact

Questions about this policy can be sent to the email address listed on the application's Google consent screen.
