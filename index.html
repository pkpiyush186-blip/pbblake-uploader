PB Blake Uploader

A private tool for scheduling short-form clips to my own YouTube channels.

What it is

PB Blake Uploader is a personal command-line tool. It uploads short video clips that I have edited myself to YouTube channels that I operate, and schedules when they publish. It is not a product, it is not offered to other people, and it has no users other than me.

What it does

  • Uploads a video file to one of my own YouTube channels
  • Sets the title, description and tags for that upload
  • Schedules the publish time, or publishes immediately
  • Reads the list of videos already on my channels, to avoid posting the same clip twice

Access it uses

It uses the YouTube Data API v3 with access granted by me, through Google sign-in, to my own channels only. It cannot see or touch anyone else's account.
